
# AWS Lambda сервисі арқылы бағдарламалық кодты іске қосу

## Жұмыстың мақсаты
AWS Lambda функциясының жұмыс принципін зерттеу
және Python тілінде серверсіз функция құру.

## Қолданылған технологиялар
- GitHub Codespaces
- Python 3
- AWS Lambda функциясының үлгісі
- JSON форматы

## Жұмыстың орындалуы
1. GitHub-та жаңа репозиторий құрылды.
2. lambda_function.py файлы жасалды.
3. Lambda функциясы жазылды.
4. test_lambda.py арқылы функция тексерілді.
5. Нәтиже терминалға шығарылды.

## Қорытынды
Жұмыс барысында Lambda функциясының құрылымы
зерттеліп, кіріс деректерін өңдеу және JSON
форматында нәтиже қайтару орындалды.

Ескерту: тест GitHub Codespaces ортасында орындалды.
Нақты AWS Lambda қызметіне орналастыру бөлек
AWS аккаунты арқылы орындалады.
